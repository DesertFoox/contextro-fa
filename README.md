# Contextro FA

پروژه دانشگاهی پردازش زبان طبیعی فارسی (NLP) برای تحلیل شباهت معنایی کلمات و بازی حدس کلمه به سبک Contexto.

## اجرای سریع

پیش‌نیاز: Python 3.11 یا بالاتر

در ویندوز فقط فایل `start.bat` را اجرا کنید. برنامه به‌صورت آفلاین روی `http://127.0.0.1:8000` اجرا می‌شود.

## قابلیت‌ها

- Semantic Similarity و Ranking فارسی
- بیش از 1,200 واژه فارسی در فضای رتبه‌بندی
- 165 کلمه هدف
- 28 حوزه معنایی و 84 زیرحوزه
- بیش از 11,000 رابطه معنایی وزن‌دار
- حدود 18,500 جفت داده آموزشی برای مسیر Fine-tuning
- Hint چندمرحله‌ای
- Semantic Journey
- نمایش نزدیک‌ترین واژه‌ها بعد از حل
- Score و Streak
- Give Up و Next Word
- AI Lab و benchmark داخلی
- مسیر آموزشی Transformer با Sentence Transformers

## ساختار پروژه

- `backend/` منطق بازی، NLP، API و training
- `frontend-static/` رابط کاربری سبک و آفلاین
- `start.bat` اجرای ساده در ویندوز
- `README-RUN.md` راهنمای اجرای سریع

## درباره امتیاز شباهت

امتیاز نزدیکی به معنی probability نیست. موتور پروژه از Rank، روابط معنایی وزن‌دار، فاصله مفهومی و ساختار گراف معنایی برای تولید proximity score استفاده می‌کند.

## Benchmark

Benchmark داخلی پروژه برای Pairwise Semantic Ordering روی مجموعه تست‌های کنترل‌شده حدود 97.5% است. این عدد accuracy عمومی زبان فارسی نیست و فقط کیفیت رتبه‌بندی داخلی پروژه را می‌سنجد.

## هدف دانشگاهی

هدف پروژه نمایش یک pipeline کامل از ساخت دیتاست معنایی فارسی، تولید جفت‌های آموزشی، رتبه‌بندی واژگان، طراحی API، رابط کاربری و مسیر Fine-tuning مدل Transformer است.
