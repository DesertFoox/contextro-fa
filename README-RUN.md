# اجرای سریع Contextro FA

## ویندوز

1. Python 3.11 یا بالاتر را نصب کنید.
2. پروژه را دانلود و Extract کنید.
3. روی `start.bat` دوبار کلیک کنید.
4. مرورگر به‌صورت خودکار روی `http://127.0.0.1:8000` باز می‌شود.

این نسخه برای اجرای استاد به‌صورت آفلاین طراحی شده و در مسیر اصلی اجرا به Docker، Node.js، npm، PyTorch یا دانلود مدل از اینترنت نیاز ندارد.

## توقف برنامه

پنجره سرور را ببندید یا `Ctrl + C` بزنید.

## بخش پژوهشی

مسیر `backend/training/` شامل دیتاست‌های آموزشی، تولید pairها، benchmark و اسکریپت Fine-tuning برای Sentence Transformers است. این بخش برای پژوهش و توسعه مدل است و برای اجرای دموی اصلی لازم نیست.
