# اجرای Contextro FA — نسخه نهایی آفلاین V3

## اجرای استاد

فقط **Python 3.11 یا جدیدتر** لازم است.

1. ZIP پروژه را Extract کنید.
2. روی `start.bat` دوبار کلیک کنید.
3. مرورگر خودکار روی `http://127.0.0.1:8000` باز می‌شود.

برای اجرای نسخه ارائه نیازی به Docker، Node.js، npm، pip install، اینترنت، PyTorch یا دانلود مدل نیست.

## رابط کاربری واقعی پروژه

فایل `start.bat` مستقیماً `backend/lightweight_server.py` را اجرا می‌کند و این سرور رابط کاربری نهایی را از مسیر زیر ارائه می‌دهد:

`backend/app/static/`

بنابراین برای بررسی فرانت نهایی پروژه باید فایل‌های `index.html`، `app.js` و `styles.css` همین پوشه بررسی شوند.

## دیتاست و فضای معنایی

- ۱٬۲۳۳ واژه فارسی در vocabulary
- ۱۶۵ کلمه هدف
- ۲۸ حوزه و ۸۴ زیرحوزه معنایی
- Semantic ontology و Cross-domain relations
- Benchmark داخلی برای بررسی ترتیب معنایی

## موتور امتیازدهی

برای هر حدس، موتور شباهت را از ترکیب ontology، روابط وزن‌دار، sparse semantic vectors، ارتباطات بین‌حوزه‌ای و fallback املایی محاسبه می‌کند. سپس Rank واژه نسبت به کل vocabulary به دست می‌آید و به یک Proximity Score قابل فهم برای بازی تبدیل می‌شود.

این امتیاز probability آماری نیست.

## مثال

اگر جواب `دریا` باشد، انتظار داریم کلماتی مثل:

- اقیانوس
- ساحل
- موج
- آب

در رتبه‌های بالا قرار بگیرند؛ در حالی که کلمات نامرتبط در محدوده سرد باقی بمانند.

## Hint و Round

هر راند تا سه Hint دارد. بعد از حل کلمه یا تسلیم‌شدن، دکمه «کلمه بعدی» ظاهر می‌شود و بازی وارد راند جدید می‌شود.

## بخش پژوهشی

نسخه آفلاین برای ارائه سبک نگه داشته شده، اما ساختار پروژه مسیر پژوهشی Fine-tuning مدل‌های Transformer و Sentence Transformers را نیز در نظر می‌گیرد. این مرحله برای اجرای دمو توسط استاد ضروری نیست.
